# sagnikdey.com

Portfolio site for Sagnik Dey — Next.js (App Router) + Tailwind CSS v4.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

- `app/` — routes: `/` (home), `/work/sagui` (case study), `/work/[slug]` (stubs for MDM, Sales Analytics)
- `components/` — one component per design-system pattern
- `content/site.ts` — all copy, projects, quotes and proof numbers
- `design-system/` — tokens, patterns and **rules for AI agents** (also referenced from `AGENTS.md`)
- `public/images/` — real product screenshots used in collages
